# Surface: index.html — direction contract

**World:** "Add website." The moment a map listing shows an empty "Add website" button, turned into a studio. Cool concrete white (#f2f3f5), ink (#0c0e12), one acid lime (#c8f53c) used only as a fill, never as text; two near-black "night" sections (the work, the contact and footer). Mona Sans stretched wide (wdth 112–125%, weight 700–820) for display, Mona Sans at normal width for reading, Martian Mono for small uppercase labels. seed: none. The user asked for something unlike the pitch-site templates, so the direction was chosen directly (pipeline memory `pitch-site-pipeline`, no concept roll).
